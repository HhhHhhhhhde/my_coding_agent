# ADR-003: 采用 Workspace 安全边界

## 状态

Accepted

## 背景

Coding agent 需要读写文件并执行命令。如果不限制执行范围，模型可能误读敏感文件、修改无关路径或执行危险命令。

## 决策

所有文件工具和命令工具都受 workspace 限制。路径必须 resolve 后仍位于 workspace 内。危险命令默认拒绝，命令执行必须有超时和输出截断。

## 后果

优点：

- 降低本地执行风险。
- 便于解释权限模型。
- 有利于稳定演示。

代价：

- Agent 无法直接处理 workspace 外部文件。
- 某些真实开发命令可能需要额外放行规则。
