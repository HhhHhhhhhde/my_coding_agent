# Requirements Spec

## 项目目标

实现一个不能建立在已有 agent 框架上的编程智能体。它通过调用大语言模型，能够在本地工作区内自主读取文件、搜索代码、修改文件、执行命令，并根据执行结果继续迭代，最终完成用户给出的真实编程任务。

本项目允许使用模型厂商 API 客户端或 OpenAI 兼容接口，但不允许使用 LangChain、LlamaIndex、OpenAI Agents SDK、Claude Agent SDK、AutoGen、CrewAI 等 agent 框架，也不依赖服务端托管的代码执行或文件工具。

## 必须实现的功能

1. 多轮 Agent Loop
   - 能接收用户任务。
   - 能调用 LLM 获取下一步动作。
   - 能执行本地工具。
   - 能把工具结果反馈给 LLM。
   - 能在完成、失败、超步数或用户中断时终止。

2. 自研工具协议
   - 模型输出必须被解析成结构化 action。
   - 本地程序负责校验 action 格式、工具名和参数。
   - 不允许模型直接获得任意本地执行权限。

3. 文件读取能力
   - 能列出目录。
   - 能按行号读取文件片段。
   - 能限制单次读取长度，避免上下文过长。

4. 代码搜索能力
   - 能在工作区内按关键词或正则搜索。
   - 搜索结果应包含文件路径、行号和匹配内容摘要。

5. 文件修改能力
   - 能创建新文件。
   - 能修改已有文件。
   - 优先支持精确替换或 patch，避免无意义整文件重写。

6. 命令执行能力
   - 能在工作区内执行测试、构建或脚本命令。
   - 命令必须有超时时间。
   - 命令输出必须截断。
   - 命令结果必须回传给 Agent Loop。

7. 安全边界
   - 所有文件路径必须限制在 workspace 内。
   - 凭据只能通过环境变量或未入库配置提供。
   - 默认拒绝读取明显敏感文件。
   - 默认拒绝或确认危险命令。

8. 运行轨迹
   - 每一步 action、参数、observation、错误和终止原因应被记录。
   - 轨迹用于调试、视频演示和面试解释。

9. 完成总结
   - Agent 结束时应说明完成了什么。
   - 应说明修改了哪些文件。
   - 应说明运行过什么验证命令及结果。
   - 如果未验证，应说明原因。

## 加分功能候选

1. Plan / Build 双模式
   - Plan 模式只允许读文件、搜索和生成方案。
   - Build 模式允许修改文件和执行命令。
   - 价值：体现权限分层和人类可控性。

2. 轻量 Repo Map
   - 启动时扫描文件树和关键符号。
   - Python 项目可提取 class、function、import。
   - 价值：减少盲目读取文件，体现上下文管理能力。

3. apply_patch 编辑工具
   - 支持统一 diff 或局部 patch。
   - 价值：比整文件写入更安全，更接近真实 coding agent。

4. 验证门禁
   - finish 前要求至少运行一次相关测试或检查。
   - 无法验证时必须说明原因。
   - 价值：体现 agent 不只会改代码，也会闭环验证。

5. 轨迹回放
   - 将 JSONL 轨迹转换成人类可读的执行报告。
   - 价值：便于视频展示和面试复盘。

6. 高风险操作确认
   - 删除文件、覆盖大文件、运行危险命令时询问用户。
   - 价值：体现本地执行安全设计。

7. 上下文压缩
   - 当历史过长时保留最近步骤，并压缩早期 observation。
   - 价值：体现对上下文窗口限制的理解。

## 明确不做

1. 不封装 Claude Code、Codex、OpenCode、DeepSeek Harness 等现成 agent 产品。
2. 不使用现成 agent 框架或 SDK。
3. 不依赖云端 Code Interpreter、Files API 或托管文件执行环境。
4. 不做多 agent 协作。
5. 不做 GUI。
6. 不做浏览器自动化。
7. 不做长期记忆系统。
8. 不做向量数据库检索。
9. 不自动 git push 或创建远程 PR。

## 成功标准

1. 能在演示项目中完成一个真实编程任务，例如修复失败测试。
2. 能展示 Agent 多轮读取、搜索、编辑、执行测试、根据错误反馈迭代的过程。
3. 能解释每个核心模块的职责和必要性。
4. 能证明项目没有依赖现成 agent 框架。
5. README.txt 控制在 1000 汉字以内。
6. 视频控制在 2 分钟以内，mp4 格式，不超过 200 MB。
